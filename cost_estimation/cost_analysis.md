# Cost Analysis

## Cost Breakdown

All figures are high-level ranges based on comparable Pflegedienst deployments and publicly available vendor pricing. Cleo should request formal quotes from voize and competing vendors during Phase A discovery.

**Year 1 — Upfront and Recurring Costs**

| Cost Item | Estimated Range | Notes |
|---|---|---|
| voize software licence (~85 caregivers, 12 months)¹ | €6,000 – €8,000 | Request volume pricing for an ~85-user deployment |
| MEDIFOX DAN API integration (one-time setup) | €1,500 – €2,500 | Complexity varies; allow a 1-week buffer |
| Staff onboarding & training (internal coordinator time) | €500 – €1,000 | Two cohort sessions + pilot onboarding |
| Legal review of AVV / DSGVO compliance | €500 – €1,000 | External counsel recommended |
| IT setup and configuration | €500 – €1,000 | Includes device management setup |
| **Subtotal (excl. devices)** | **~€9,000 – €13,500** | |
| Device hardware — company smartphones, if required | €0 – €8,500 | €100–€200 per device × ~85 caregivers¹ |
| **Total Year 1 (worst case, incl. devices)** | **~€17,500 – €22,000** | |

> ¹ ~85 caregivers is a sector-benchmark estimate for a Pflegedienst of this size, not a verified internal figure.

> **Device note:** If Cleo already issues smartphones, the hardware line is €0. If not, leasing options are available and may spread this cost across 24–36 months.

**Year 1 Benefit Estimate**

| Metric | Estimate |
|---|---|
| Documentation time saved (27% of ~10% of caregiver hours) | ~2,200 hours/year² |
| Value of recovered capacity (€16/hr blended rate) | €35,200² |
| Net Year 1 benefit (excl. devices) | €21,700 – €26,200 |
| Net Year 1 benefit (incl. devices, worst case) | €13,200 – €17,700 |
| Payback period (excl. devices) | 4–5 months |
| Payback period (incl. devices) | 6–8 months |
| Estimated Year 2+ net annual benefit | ~€26,000 – €28,500 |

> ² Based on sector-average 10% documentation time and an estimated ~85 field caregivers at the assumed company size — a sector-benchmark-derived figure, not internally verified.

## Assumptions

- **27% documentation time reduction** is used as the benefit baseline, sourced from the Charité Berlin PYSA study (peer-reviewed, n=52, 770h). The voize vendor-claimed 61% figure is not used — it reflects an optimistic pilot environment rather than steady-state operations.
- **Blended caregiver hourly rate of €16** is consistent with published German ambulatory care sector benchmarks (Tarifvertrag Caritas / AWO scale).
- **Documentation time = 10% of total caregiver hours** is a sector average. Cleo's actual figure should be established in the Phase A 2-week time-tracking exercise — this is the highest-leverage assumption in the model.
- Software licence pricing is indicative. voize and competitors (Sprachassistent Pflege, Mentalab) may negotiate volume rates for a deployment of this size.
- Benefit figures assume freed documentation time is redirected to client care or used to absorb existing overtime — not that headcount is reduced.

> **Note on figures:** All staff and client figures in this document are sector-benchmark estimates for a mid-sized ambulatory Pflegedienst. No internal Cleo data was used.
